三種窗長取交集

同一段落在 4、8、10 秒窗下可能得到不同類別。要較嚴格的素材，可只取三種窗長都判為同一純類別的時段。每首每 1 秒取一點（t＝0.5、1.5…）：

  • 嚴格：涵蓋該點的每個窗，在三種窗長下都判同一純類別。純樂器 44.82 小時、純雜音 5.33 小時。
  • 寬鬆（下方範例的算法）：各窗長只取中心最近的窗，三者同類。純樂器 54.03 小時、純雜音 7.28 小時。

對照：只用 8 秒窗是純樂器 76.25 小時、純雜音 13.25 小時。純雜音縮減最多，表示許多純雜音時段至少在一種窗長下被判為混合。

import numpy as np, pandas as pd
W = {w: pd.read_parquet(f"windows_class_w{w}.parquet") for w in (4, 8, 10)}
def per_second(d):
    d = d.assign(c=(d.start + d.end) / 2)
    out = []
    for k, g in d.groupby("stem_path", observed=True):
        t = np.arange(0.5, g.end.max(), 1.0)
        i = np.abs(t[:, None] - g.c.to_numpy()).argmin(1)
        out.append(pd.DataFrame({"stem_path": k, "t": t, "cls": g["class"].astype(str).to_numpy()[i]}))
    return pd.concat(out).set_index(["stem_path", "t"]).cls
L = pd.concat({w: per_second(d) for w, d in W.items()}, axis=1, join="inner")
strict = L[(L[4] == L[8]) & (L[8] == L[10]) & L[8].isin(["pure_instrument", "pure_noise"])]

方法

  • 資料：日治時期至戰後的臺灣唱片數位化檔案，以 demucs htdemucs 分離為人聲與伴奏兩軌；本頁只統計伴奏軌。載體分為戰前 78 轉、日文 78 轉、戰後 78 轉、黑膠與錄音帶。
  • 切段：8 秒窗、步距 4 秒；每段先以 RMS 判斷靜音（低於 -60 dB）。
  • 模型：AST（MIT/ast-finetuned-audioset-10-10-0.4593，AudioSet 527 類）與 LAION-CLAP（clap-htsat-unfused，零樣本提示詞 v3）。兩個模型各輸出前 10 名。
  • 純樂器：max(Music, 樂器類) ≥ 0.2，人聲類 < 0.05，且 CLAP 第一名為樂器類提示詞。
  • 純雜音：Music、樂器類、人聲類都 < 0.05，且 CLAP 第一名為唱片表面雜音類提示詞。
  • 混合：上述條件不一致者。規則以精確率優先，不確定的段落一律歸入混合。
  • 區間：滑鼠移到長條上可看 95% Wilson 信賴區間。區間以段為單位計算；相鄰窗重疊、同一首內的段落高度相關，實際不確定性大於區間所示。
  • 下一步：以人工試聽的黃金標準校正門檻，並以 Wilson 下界控制各類別的精確率。
